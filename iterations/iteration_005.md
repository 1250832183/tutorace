## Phase 1: 对抗性 Persona

### Persona: 急躁的学霸小张

**对抗性假设**:
> 我假设系统可能无法很好地处理**已经有基础知识、想要快速学习、不想听基础解释**的中文用户

**核心特征**:
- 学习能力强，已有相关背景知识
- 不耐烦听基础解释，想直接跳到重点
- 用中文的含蓄方式表达不满（不会直接说"太长了"）

**行为模式**:
- 打断 Agent 说"这个我知道"
- 要求"直接说重点"或"说点我不知道的"
- 用"嗯嗯"、"好的好的"等敷衍回应暗示不耐烦
- 问深入的问题测试 Agent 的知识深度

**典型语句**:
- "这个我知道，说点别的"
- "嗯嗯，然后呢？"（暗示快点说完）
- "能不能直接说重点？"
- "这个太基础了，有没有更深入的？"
- "好的好的，下一个"

## Phase 3-5: 问题收集、设计思考、实现修复

### 问题定义

**问题**: Agent 无法识别中文用户的含蓄不耐烦表达

| 用户输入 | Agent 理解 | 实际意图 | 问题 |
|---------|-----------|---------|------|
| "嗯嗯，然后呢？" | 请继续说更多 | 快点说完/跳过 | Agent 继续提供长回复 |
| "好的好的" | 确认理解 | 不耐烦，想快点结束 | Agent 没有简化 |

### 设计思考

根据 SOP 核心原则：
- **不增加按钮/模式/选项**
- **让 Agent 更智能地理解和响应用户**

### 修复方案

在中文 Agent 的 `SYSTEM_PROMPTS["zh"]` 中添加以下内容：

```
识别中文用户的含蓄不耐烦表达（非常重要）：
当用户说以下内容时，这是他们想快速推进的信号：
- "嗯嗯"、"好的好的"、"行行行"、"知道了知道了" = 敷衍式回应，想快点结束当前内容
- "这个我知道"、"这个我懂" = 用户已有基础知识，想跳过基础解释
- "然后呢？"、"下一个"、"继续" = 用户想快速推进到下一个话题
- "说重点"、"直接说结论" = 用户想要简短的总结

当检测到这些信号时，你必须：
1. 立即停止当前的长解释
2. 用1-2句话简短总结核心要点
3. 主动说"好的，我们直接进入下一页吧！点击箭头继续。"
4. 不要继续展开或提供更多细节
```
